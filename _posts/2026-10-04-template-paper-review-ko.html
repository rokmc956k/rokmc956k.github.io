2. Opening: 두세 문단 안에 논문을 설명

첫 문단에서는 바로 세 가지를 답한다. 어떤 문제를 푸는가, 핵심 아이디어는 무엇인가, 왜 결과가 중요한가? 구현 디테일이나 수식부터 시작하지 않는다. 독자는 notation을 보기 전에 논문의 thesis를 이해할 수 있어야 한다.

Core idea: 논문의 핵심 기술적 전환을 한두 문장으로 요약한다. 이 박스만 읽어도 논문의 요지를 이해할 수 있어야 한다.

3. 선택 사항: KPI snapshot

기억할 만한 실험 결과가 있다면 초반에 3–4개 정도만 보여준다. scale, success rate, model/data size, hardware transfer처럼 논문의 주장 이해에 직접 도움이 되는 수치만 사용한다.

[Metric]이 숫자가 의미하는 것
[Scale]robots / tasks / data / model size
[Result]주요 성능 향상
[Hardware]실환경 플랫폼 또는 deployment

4. Problem and motivation

왜 어려운 문제인지, 기존 접근에서 무엇이 깨지는지 설명한다. Robotics 논문에서는 observation/action space, contact 및 embodiment 제약, coordination assumption, sim-to-real gap 등을 명확히 적는다.

5. Core abstraction / architecture

수식보다 먼저 논문의 핵심 representation과 system decomposition을 설명한다. 구조가 복잡하면 원본 그림을 그대로 복사하기보다 이해하기 쉬운 reconstructed diagram을 우선한다.

6. Mathematical formulation

방법 이해에 필요한 수식만 포함한다. 기호를 정의하고, 식 다음 문단에서는 단순히 식을 반복하지 말고 이 식이 왜 중요한지 설명한다.

예:

$$ \mathbf{y}=f_{\theta}(\mathbf{x}), $$

$\mathbf{x}$는 state/observation, $f_\theta$는 learned 또는 optimized model, $\mathbf{y}$는 control/policy/task output이라고 설명하고 실제 system 의미와 연결한다.

7. Training / optimization / system pipeline

실제 recipe를 정리한다: algorithm, curriculum, losses/rewards, data flow, simulator, initialization, parallel environments, compute, fine-tuning stage, frozen/trainable component. 결과를 설명하는 중요한 선택을 중심으로 쓴다.

Implementation detail worth remembering: 실제 재현이나 다른 프로젝트 적용 시 중요할 하나의 practical detail을 기록한다.

8.1 Generalization / ablation / scaling

논문의 중심 주장을 가장 강하게 검증하는 실험을 넣는다. unseen object, larger team size, new task, real hardware, ablation, robustness 등이 대표적이다. 과장하지 않도록 evaluation 조건도 함께 적는다.

9. Why this paper matters

단순 요약이 아니라 해석을 적는 부분이다. 어떤 capability 또는 연구 방향을 바꾸는지, 어떤 assumption을 줄였는지, VLA/RL/humanoid/manipulation/sim-to-real 맥락에서 어디에 위치하는지 설명한다.

10. Limitations and open questions

  • Assumptions: privileged information, frozen controller, simulator, object model, task structure 의존성
  • Evaluation: 아직 빠진 조건이나 benchmark
  • Scalability: task/robot/data/compute 증가 시 문제
  • Real-world gap: simulation-only 결과
  • Research question: 다음으로 가장 가치 있는 실험
